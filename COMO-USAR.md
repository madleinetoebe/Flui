# Atualização do CashTrack (Expo)

1. Copie TUDO desta pasta para dentro de Documents\flui, substituindo os arquivos:
   App.tsx, pasta lib, pasta components, pasta screens e pasta supabase.
   (O .env e a pasta assets continuam como estão.)

2. No cmd:
   cd %USERPROFILE%\Documents\flui
   npx expo install expo-image-picker

3. No Supabase: SQL Editor > New query > cole o conteúdo de supabase\novas-tabelas.sql > Run.

4. Rode o app:
   npx expo start -c
